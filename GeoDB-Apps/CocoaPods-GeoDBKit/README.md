# GeodbKit for CocoaPods

High-performance geographic database for iOS. Powered by Rust.

## Installation

### Local Path Installation (Recommended for Development)

Add to your `Podfile`:

```ruby
platform :ios, '13.0'
use_frameworks!

target 'YourApp' do
  pod 'GeodbKit', :path => '/path/to/geodb-rs/GeoDB-Apps/CocoaPods-GeoDBKit'
end

# Required for Apple Silicon simulators (only arm64 supported)
post_install do |installer|
  installer.pods_project.targets.each do |target|
    target.build_configurations.each do |config|
      config.build_settings['EXCLUDED_ARCHS[sdk=iphonesimulator*]'] = 'i386 x86_64'
    end
  end
end
```

Then run:

```bash
pod install
```

### Alternative: Swift Package Manager

For native iOS apps, consider using the SPM package instead:
- Location: `GeoDB-Apps/SPM-GeoDBKit/`
- In Xcode: File > Add Packages > Add Local > Select SPM-GeoDBKit folder

## Usage

### Swift

```swift
import GeodbKit

// Initialize the database engine
let engine = try GeoDbEngine()

// Get database statistics
let stats = engine.getStats()
print("Countries: \(stats.countryCount), Cities: \(stats.cityCount)")

// Search for cities
let cities = try engine.findCitiesBySubstring(query: "Berlin", limit: 10)
for city in cities {
    print("\(city.name), \(city.stateName ?? ""), \(city.countryName)")
}

// Find nearest cities to coordinates
let nearest = try engine.findNearest(lat: 52.52, lon: 13.405, limit: 5)
for city in nearest {
    print("\(city.name) - \(city.distanceKm ?? 0) km away")
}

// Find cities within radius
let inRadius = try engine.findInRadius(lat: 48.8566, lon: 2.3522, radiusKm: 50.0, limit: 20)

// Smart search (combines countries, states, cities)
let results = try engine.smartSearch(query: "New York", limit: 10)
```

### Available Methods

| Method | Description |
|--------|-------------|
| `getStats()` | Get database statistics (counts) |
| `getCountryCount()` | Number of countries |
| `findCountryByCode(iso2:)` | Find country by ISO2 code |
| `findCountriesBySubstring(query:limit:)` | Search countries by name |
| `findStatesBySubstring(query:limit:)` | Search states/regions by name |
| `findCitiesBySubstring(query:limit:)` | Search cities by name |
| `findNearest(lat:lon:limit:)` | Find N nearest cities to coordinates |
| `findInRadius(lat:lon:radiusKm:limit:)` | Find cities within radius |
| `smartSearch(query:limit:)` | Combined search across all entity types |

### CityResult Properties

```swift
struct CityResult {
    let id: UInt32
    let name: String
    let stateName: String?
    let stateCode: String?
    let countryName: String
    let countryCode: String
    let latitude: Double
    let longitude: Double
    let distanceKm: Double?  // Only populated for spatial queries
}
```

## Platform Support

| Platform | Version | Notes |
|----------|---------|-------|
| iOS Device | 13.0+ | arm64 |
| iOS Simulator | 13.0+ | arm64 only (Apple Silicon Macs) |

**Note:** x86_64 (Intel Mac) simulators are not supported. The XCFramework only includes arm64 simulator slices.

## Requirements

- Xcode 15+
- Swift 5.0+
- CocoaPods 1.10+
- Apple Silicon Mac (for simulator testing)

## How It Works

GeodbKit is built from:
1. **geodb-core** - Rust library with the geographic database
2. **geodb-ffi** - UniFFI bindings for cross-language support
3. **GeodbFfi.xcframework** - Pre-compiled iOS framework
4. **geodb_ffi.swift** - Swift bindings generated by UniFFI

The database (~17MB) is embedded in the framework binary, so no network calls are needed.

## Building from Source

If you need to rebuild the XCFramework:

```bash
# From the geodb-rs root directory
./scripts/build_spm_universal.sh

# Create iOS-only XCFramework for CocoaPods
cd GeoDB-Apps/CocoaPods-GeoDBKit
xcodebuild -create-xcframework \
  -framework ../SPM-GeoDBKit/GeodbFfi.xcframework/ios-arm64/GeodbFfi.framework \
  -debug-symbols "$(pwd)/../SPM-GeoDBKit/GeodbFfi.xcframework/ios-arm64/dSYMs/GeodbFfi.framework.dSYM" \
  -framework ../SPM-GeoDBKit/GeodbFfi.xcframework/ios-arm64-simulator/GeodbFfi.framework \
  -debug-symbols "$(pwd)/../SPM-GeoDBKit/GeodbFfi.xcframework/ios-arm64-simulator/dSYMs/GeodbFfi.framework.dSYM" \
  -output GeodbFfi-iOS.xcframework
```

## Troubleshooting

### "Unable to install vendored xcframework"

The full XCFramework contains mixed static/dynamic libraries. Use the iOS-only `GeodbFfi-iOS.xcframework` which only has dynamic libraries.

### "Missing slice for x86_64"

The XCFramework only supports arm64 simulators. Add to your Podfile:

```ruby
post_install do |installer|
  installer.pods_project.targets.each do |target|
    target.build_configurations.each do |config|
      config.build_settings['EXCLUDED_ARCHS[sdk=iphonesimulator*]'] = 'i386 x86_64'
    end
  end
end
```

### Module 'GeodbFfi' not found

Ensure you're using `use_frameworks!` in your Podfile and that the XCFramework was copied correctly.
